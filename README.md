# chick-chirick бэкенд

Это "Pet" приложение на Go должно реализовать функционал асинхронного мессенджера.
Дальнейшее развитие предполагает разбиение реализованного монолита на микросервисы,
а в будущем, возможно, и полностью функциональный прототип, развернутый в продакшен 
окружении. В директории docs можно найти более детальное описание архитектуры и отследить
флоу развития приложения.

# Зависимости 

На текущий момент проект зависит от библиотек: 

* https://github.com/spf13/viper - ресолвер конфигов приложения
* https://github.com/go-gorm/ - ORM
* github.com/redis/go-redis/v9 - Redis


# Запуск приложения 

1. В корне приложения создать .env файл по шаблону из .env.dist. Указать 
параметры в зависимости от окружения 
2. Выполнить Docker-compose build (--no-cache без кэшей)
3. Выполнить Docker-compose up (-d фоном)
4. Если требуется запуск исполняемого бинарника локально, а не
в контейнере - необходимо локально создать директорию /app и поместить в неё
.env файл приложения
